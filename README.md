# GGG Studio Docs

This repository contains the lightweight, ChatGPT-readable studio documentation for Golden Griffin Gaming.

## Start Here

- `READ_FIRST.md` — front door for the studio docs
- `GGG_Project_Status.md` — current active projects and focus
- `Production_Discipline.md` — done definition, versioning, and build rules
- `Templates/` — reusable devlog, concept, and brainstorm templates

## Purpose

This repo is for tracking studio documentation, planning, project status, and reusable templates.

Large art files, builds, PSD/AF files, videos, and exports should stay outside this repo.
