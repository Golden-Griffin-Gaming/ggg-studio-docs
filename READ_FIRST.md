2. Administrative/GGG_Studio_Structure_v1.0.pdf

4. Templates/

## Current Rule

Before starting new work, check:
- What is active?
- What is the current focus?
- What is the smallest useful next step?

New ideas go into Notes/Ideas unless promoted later.
